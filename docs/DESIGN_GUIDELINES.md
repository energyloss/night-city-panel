# Design guidelines

The visual language is cyberpunk / neo-noir / urban decay: restrained neon,
rainy-city atmosphere and readable information over decorative effects.

## Tokens

| Token | Value |
|---|---|
| Background | `#181C2B` |
| Surface | `#292E42` |
| Neon blue | `#79A6FF` |
| Acid green | `#A4D65E` |
| Neon violet | `#BE8AFF` |

Start with 16–28px card radii. Use subtle glow only; avoid continuous blur and
full-screen post-processing. All interactive elements need visible focus
states. Support 12/24-hour time, localized formats, HiDPI, long text and
reduced motion. CRT/glitch effects must have an off switch.
